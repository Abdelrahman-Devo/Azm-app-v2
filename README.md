# Azm – عزم

تطبيق Flutter عربي لبناء العادات والانضباط الشخصي.

## تشغيل المشروع
1. ثبّت Flutter SDK (قناة stable) و Android SDK.
2. من مجلد المشروع نفّذ:
   ```bash
   flutter pub get
   flutter run
   ```
3. لبناء APK:
   ```bash
   flutter build apk --release
   ```
   الملف الناتج: `build/app/outputs/flutter-apk/app-release.apk`

## رفع الملفات من الهاتف إلى GitHub
ارفع محتويات هذا المجلد إلى جذر المستودع `azm-app`، وليس مجلد `azm-app` نفسه.

## الموجود في هذه النسخة
- واجهة عربية RTL وهوية كحلية/خضراء.
- لوحة يومية ونسبة إنجاز.
- إضافة وتعديل وحذف العادات.
- جدول أيام الأسبوع ومدة العادة.
- مؤقت جلسة يبدأ/إيقاف مؤقت/استكمال.
- حفظ العادات والجلسة محليًا عبر SharedPreferences.
- سجل إكمال أساسي ونقاط XP أولية.
- وضع فاتح/داكن محفوظ.

## حدود النسخة الحالية
هذه نسخة تأسيسية قابلة للتشغيل وليست ادعاءً باكتمال كل نطاق Azm. لم يتم بعد تنفيذ المصادقة السحابية، Drift/SQLite، المزامنة، الأصدقاء، AI، حظر التطبيقات، الإشعارات المجدولة، رفع الصور الآمن، أو اختبارات الأجهزة الفعلية. لا ترفع مفاتيح Supabase أو أي أسرار إلى GitHub.

## بناء APK عبر GitHub Actions
بعد رفع الملفات، افتح تبويب Actions وشغّل workflow `Build Android APK` أو ادفع commit جديدًا. نزّل artifact باسم `azm-release-apk` بعد نجاح البناء.
